# Правила проекта

- Один день плана из ROADMAP.md — один коммит. Сообщение коммита берётся из колонки «Коммит».
- После каждого нового коммита с готовой версией игры (день плана) сразу
  отправляй его на GitHub: `git push origin main`. Отдельного разрешения не нужно.
- Пушить можно только когда игра запускается и играется. Если проверка не
  прошла — сначала чини, потом коммить и пушь.
- Force-push и переписывание уже отправленной истории — только по прямой просьбе.
- Игра запускается через локальный сервер (`python -m http.server 8000`), ES-модули, без сборки.
