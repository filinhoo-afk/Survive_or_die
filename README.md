# Survive or Die

Аркадная игра на выживание в браузере: бегаешь, отбиваешься от толп, качаешь
апгрейды. Чистый JavaScript + Canvas, без фреймворков и сборки.

К 70-му дню — собственная пиксельная графика, кампания из четырёх локаций
с боссами и онлайн-таблица рекордов.

Учебный проект по вайбкодингу: **70 дней, по одному коммиту в день.**
План на все 70 дней — в [ROADMAP.md](ROADMAP.md).

## Как запустить

Игра использует ES-модули, поэтому её нужно открывать через локальный сервер,
а не двойным кликом по `index.html`.

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Управление

| Клавиши          | Действие |
|------------------|----------|
| `W` `A` `S` `D`  | движение |
| Стрелки          | движение |
| `1` `2` `3`      | выбор улучшения при новом уровне |
| `N`              | выключить / включить звук |

Мир больше экрана: 2880 × 1800 против видимых 960 × 540. Камера плавно
следует за игроком и прижимается к границам, не показывая пустоту за краем.
Положение в мире видно в HUD и на миникарте в правом верхнем углу.

## Структура

```
index.html          точка входа
css/style.css       оформление страницы
src/
  config.js         все настройки в одном месте
  main.js           сборка игры, update/render
  engine/
    loop.js         игровой цикл с фиксированным шагом
    input.js        клавиатура
    camera.js       камера: следование за игроком и упор в границы мира
  entities/
    player.js       игрок
    enemy.js        враг любого типа и расталкивание толпы по массам
    projectile.js   снаряд автоатаки
    enemyShot.js    снаряд врага-стрелка: бьёт только игрока
    gem.js          кристалл опыта с магнитом
  enemies/
    types.js        типы врагов: обычный, рой, танк, стрелок
  systems/
    spawner.js      волны врагов из-за края экрана
    damage.js       урон: касания врагов и попадания снарядов
    weapons.js      оружие: уровни, перезарядка, чистка снарядов
    arsenal.js      набор оружия игрока, до 6 штук
    targeting.js    поиск ближайших целей
    effects.js      визуальные эффекты: смерть врага, повышение уровня
    pickups.js      сбор кристаллов опыта
    upgrades.js     карточки улучшений: оружие и пассивки
    records.js      локальный рекорд в localStorage
  weapons/
    cannon.js       пушка: бьёт по ближайшим врагам
    knife.js        нож: летит по взгляду, пробивает насквозь
    orbit.js        щит: шары кружат вокруг игрока
    aura.js         аура: жжёт всех врагов вокруг
    index.js        список всех оружий
  ui/
    upgradeScreen.js  экран выбора улучшения
    summaryScreen.js  экран итогов забега против рекорда
    format.js         формат времени и чисел
```

## Прогресс

- [x] День 2 — камера, мир больше экрана, миникарта
- [x] День 3 — первый враг: бежит к игроку, враги не слипаются
- [x] День 4 — спавн врагов волнами из-за края экрана
- [x] День 5 — здоровье игрока, урон от касания, неуязвимость после удара
- [x] День 6 — автоатака: снаряды летят в ближайшего врага
- [x] День 7 — попадания, здоровье врагов, вспышка, отброс и смерть
- [x] День 8 — кристаллы опыта, магнит, уровни и полоса опыта
- [x] День 9 — экран выбора улучшения: три карточки, мир на паузе
- [x] День 10 — общая система оружия с уровнями, метательный нож
- [x] День 11 — орбитальный щит и аура урона
- [x] День 12 — пассивки: сила, спешка, размах, регенерация, броня
