# Survive or Die

Аркадная игра на выживание в браузере: бегаешь, отбиваешься от толп, качаешь
апгрейды. Чистый JavaScript + Canvas, без фреймворков и сборки.

К 70-му дню — собственная пиксельная графика, кампания из четырёх локаций
с боссами и онлайн-таблица рекордов.

Учебный проект по вайбкодингу: **70 дней, по одному коммиту в день.**
План на все 70 дней — в [ROADMAP.md](ROADMAP.md).

## Как запустить

Игра использует ES-модули, поэтому её нужно открывать через локальный сервер,
а не двойным кликом по `index.html`.

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Управление

| Клавиши          | Действие |
|------------------|----------|
| `W` `A` `S` `D`  | движение |
| Стрелки          | движение |
| `1` `2` `3`      | выбор улучшения при новом уровне |

Мир больше экрана: 2880 × 1800 против видимых 960 × 540. Камера плавно
следует за игроком и прижимается к границам, не показывая пустоту за краем.
Положение в мире видно в HUD и на миникарте в правом верхнем углу.

## Структура

```
index.html          точка входа
css/style.css       оформление страницы
src/
  config.js         все настройки в одном месте
  main.js           сборка игры, update/render
  engine/
    loop.js         игровой цикл с фиксированным шагом
    input.js        клавиатура
    camera.js       камера: следование за игроком и упор в границы мира
  entities/
    player.js       игрок
    enemy.js        враг-преследователь и расталкивание толпы
    projectile.js   снаряд автоатаки
    gem.js          кристалл опыта с магнитом
  systems/
    spawner.js      волны врагов из-за края экрана
    damage.js       урон: касания врагов и попадания снарядов
    weapons.js      автопушка: выбор цели и выстрелы
    effects.js      визуальные эффекты: смерть врага, повышение уровня
    pickups.js      сбор кристаллов опыта
    upgrades.js     улучшения: список и учёт взятых
  ui/
    upgradeScreen.js  экран выбора улучшения
```

- [x] День 7 — попадания, здоровье врагов, вспышка, отброс и смерть
